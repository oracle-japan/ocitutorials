MySQL HeatWaveのDBシステムを新規作成し、運用と分析を順に体験するチュートリアルです。Cloud Shell上のMySQL Shell Communityを使い、Computeを転送専用のSSH経路として接続します。

初めて利用する方は101から順に進めてください。既存のMySQLチュートリアルを完了している必要はありません。OCIへのサインイン、ネットワークとComputeの準備は101の前提条件で確認します。

DBシステムはデータを保存・更新するMySQLの環境です。分析専用のHeatWaveクラスタは201で追加するため、101では不要です。基礎編だけなら101〜106、全機能を体験するなら101〜105→106の監視・費用確認→201〜204→106の後片付けの順に進みます。

## 操作する場所を見分ける

|画面・プロンプト|ここで行うこと|
|---|---|
|OCIコンソール|ブラウザでDBなどを作成・変更・削除する|
|Cloud ShellのOSプロンプト（通常は末尾が `$`）|クライアントの導入、SSH転送、ファイル操作を行う|
|MySQL Shellの `SQL >`|DBに接続してSQLを実行する|
|MySQL Shellの `JS >`|104のdump/loadなど、JavaScript形式の管理操作を行う|

Cloud Shellは端末環境、MySQL Shellはその中で動かすDBクライアントです。MySQL Shell内では `\sql` / `\js` でモードを切り替え、`\quit` でOSへ戻ります。コマンドは本文の枠からコピーし、画面例のプロンプトや出力結果は貼り付けません。大文字の仮値や山括弧付きの値は、自分の環境の値へ置き換えます。
